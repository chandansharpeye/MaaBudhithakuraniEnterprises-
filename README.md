# Maa Budhi Thakurani Enterprises — Static Website

Mobile accessories catalogue and customer quotation website for Maa Budhi Thakurani Enterprises, Brahmapur, Odisha.

## Included
- Existing storefront, product catalogue, categories and product photos
- Mobile-friendly product browsing and cart
- Customer details and UPI / Cash on Delivery payment preference
- Printable quotation page (browser Print → Save as PDF)
- WhatsApp follow-up link with quotation reference and order details
- Delivery charges confirmed manually by the owner

## Hosting on GitHub Pages
1. Extract this ZIP.
2. Create or open the GitHub repository.
3. Upload the contents of the `storefront` folder to the repository root (so `index.html` is at the root), or configure Pages to publish `/storefront` if using a branch-based setup that supports that folder.
4. In GitHub, open Settings → Pages and publish from the chosen branch/folder.

## Important operating notes
- This is a static website: no backend, database, Supabase, admin login, or central order storage.
- Product details, prices, stock and MOQ already present in the source catalogue are retained, but the original project marks some details as unverified. The owner must confirm them before public launch.
- GST and delivery charges are not calculated; the owner confirms them on WhatsApp.
- UPI ID is not configured yet. The customer can choose UPI as a preference, but must wait for verified payment instructions from the owner. No payment is collected or verified by this website.
- The generated document is an enquiry quotation, NOT a tax invoice and NOT an order confirmation.
- WhatsApp opens a prefilled message. The customer must review and send it. The website cannot silently send messages or PDF attachments. Use the quotation page's Print → Save as PDF option, then attach the PDF in WhatsApp if desired.
- Cart data is stored only in the customer's browser. Orders are not centrally saved.
